# caliniya's agent frame

CAF 是 Go/Wails 制作的 Agent 框架软件。

目前支持 OneBot 11 反向 WebSocket基本集成
未来计划实现内置编辑器
计划实现插件等扩展功能

开发辅助脚本放在 [tool](tool/README.md)，包括 WSL 中固定 Windows 主机名的配置工具。
