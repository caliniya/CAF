# 2026-11-04

## 前端代码审阅 + 修复三处缺陷

技术栈：Vue 3.5 + TS + Pinia + vue-router(hash) + Vite 8 + Wails v2，无 UI 框架，手写 CSS。
源码集中在 `frontend/src`（pages / components / stores / styles）。

修复内容：
1. `components/ConfigCard.vue` `submitRename()`：判断写反导致"名字没变才保存"。改为未变化直接 return，变化才 `store.rename()`。
2. `components/SidebarTasks.vue`：v-for 内的字符串 ref 在 Vue 3 会被收集成数组导致聚焦失效。改为函数 ref `:ref="setRenameInput"` + `HTMLInputElement` 类型收窄。
3. `pages/ChatPage.vue`：composer 的 Enter 发送未判断 `isComposing`，中文输入法候选态按 Enter 会误发。改为 `@keydown.enter.exact="onComposerEnter"`，内部判断 `event.isComposing || keyCode === 229`。

已知遗留（未修）：
- `App.vue` 的 `ready` computed 为死代码（状态灯已移除）。
- `configs.ts` 的 `isEnabled` 按 `ServerAddress` 比较，同地址多配置会误判"已启用"。
- `chat.permission` 仅前端本地状态，未传给后端；`SettingsGeneralPage` 全为占位、无持久化。
